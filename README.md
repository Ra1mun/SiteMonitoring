# Site Monitoring

## Предметная область:
Пользователи добавляют URL-адреса, система периодически проверяет их доступность.

## Сущности:
Monitor (URL, название, интервал проверки, пользователь, активность), Check (монитордата, статус-код, время ответа, размер ответа), User, Notification (монитор, канал, событие).

## Специфичные требования:
-  Фоновый чекер: для каждого активного монитора запускается проверка по расписанию. Использовать setInterval или библиотеку node-cron. Параллелизм через Worker Threads или ограничение конкурентности.
- История проверок с пагинацией. Расчёт аптайма в процентах за период.
- Уведомление при смене статуса (доступен → недоступен и наоборот) — запись в лог + опционально webhook.

# Запуск

```sh
docker compose up --build
```

- API: http://localhost:3000
- Swagger UI: http://localhost:3000/docs
- OpenAPI: http://localhost:3000/openapi.json
